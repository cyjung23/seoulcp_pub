## 1. 개요

Seoul Clinic Pick(SCP)에 입점하려는 병원(성형외과, 피부과, 시술 클리닉 등)의 문의 접수부터 사이트 공개까지 전 과정을 표준화한 플레이북입니다.

## 2. 전체 프로세스 흐름

| 단계 | 작업 | 담당 | 소요시간 |
|---|---|---|---|
| 1 | 문의 접수 (이메일 수신) | 기획1팀 | 즉시 |
| 2 | 병원 홈페이지 URL 확인 | 기획1팀 | 5분 |
| 3 | robots.txt 및 크롤링 가능 여부 확인 | 기획1팀 | 5분 |
| 4 | 홈페이지 자료 수집 (크롤링) | 기획1팀 | 30분~1시간 |
| 5 | 수집 데이터 검토 및 최소 기준 판정 | 기획1팀 | 15분 |
| 6 | 이메일 회신 (수집 결과 + 보강 요청) | 기획1팀 | 30분 |
| 7 | 병원 회신 대기 및 보강 자료 수령 | - | 가변 |

**총 소요기간:** 1~2주 (병원 회신 속도 및 추가 자료량에 따라 변동)

## 3. 최소 등록 기준

다음 중 하나 이상을 충족해야 등록 가능:

- 시술 목록 1개 이상 확보
- 보유 장비 1개 이상 확보

**둘 다 없는 경우:** 등록 보류. 관련 조치는 s2-06-changelog.md 참조 (clinic_treatments와 clinic_devices가 모두 0이면 robots noindex nofollow 처리).

## 4. 필수 확인 항목 (병원별)

크롤링으로 확보하기 어려워 이메일 문의가 필요한 4가지:

1. **정확한 주소** — 크롤링 결과와 일치 여부 확인
2. **운영시간** — 평일 / 토요일 / 일요일·공휴일
3. **다국어 상담 지원** — 영어·일본어·중국어 가능 여부
4. **가격 공개 정책** — SCP 페이지 표시 여부 (비공개 가능)

## 6. 입점 문의 대응 원칙

- 회신 지연 시 사과 문구 포함
- 크롤링 결과를 먼저 보여주어 병원 부담 최소화 (서류 요청 최소)
- 무료 운영 명시: "SCP는 미용의료 정보를 제공하는 플랫폼이며, 무료로 운영하고 있습니다"
- 유료 광고 상품은 현재 미운영 안내
- 사업자등록증·의료진 정보 등 별도 서류는 원칙적으로 불필요 (단, 로그인 계정 발급 시 필요할 수 있음 명시)
