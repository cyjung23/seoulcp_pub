# s8-03. 정보 수집 체크리스트

**파일 버전:** s8-03
**소속:** 기획1팀
**업데이트:** 2026-09-14

---

## 1. 개요

병원 입점 시 크롤링으로 확보 가능한 항목과 이메일로 별도 문의해야 하는 항목을 구분한 체크리스트. s8-02 크롤링 가이드를 실행한 뒤 이 문서로 완결성을 검증합니다.

## 2. 항목별 확보 방식

### 2-1. 크롤링으로 자동 확보 (통상 성공)

- 병원명 (한글 / 영문)
- 대표 전화번호
- 홈페이지 URL
- 시술 목록 (한글명 기준)
- 보유 장비 목록 (한글명·영문명·제조사)
- 시술과 장비의 매핑 관계 (리프팅 시술이 어떤 장비를 사용하는지 등)
- 카테고리 분류 (리프팅·주사·성형수술 등)

### 2-2. 크롤링 부정확·누락 빈발 (수동 검증 필수)

- 정확한 주소 (건물명·층수 포함)
- 지역구 (서초구·강남구 등)
- 운영시간 (평일·토요일·일요일·공휴일)
- 다국어 상담 지원 여부 (영어·일본어·중국어)
- 시술 가격
- 시술 소개 이미지

이 항목들은 크롤링으로 잡히더라도 반드시 병원 회신으로 재확인.

### 2-3. 이메일 문의 필수 4가지

병원에 보내는 첫 회신 이메일에 항상 포함:

1. **정확한 주소**: 크롤링으로 확인된 주소를 명시하며 "맞을까요?" 형식으로 확인 요청
2. **운영시간**: 평일 / 토요일 / 일요일·공휴일 진료시간
3. **다국어 상담 지원**: 영어·일본어·중국어 상담 가능 여부
4. **가격 공개 정책**: SCP 페이지에 시술 가격을 표시할지, 비공개로 할지 (비공개도 선택 가능)

## 3. 등록 최소 기준 판정 체크

크롤링 결과를 이 순서로 검증:

- [ ] JSON 파일이 정상 생성되었는가 (output/clinics_v3/[clinic_id].json)
- [ ] 병원명(한글) 필드가 채워져 있는가
- [ ] 전화 또는 홈페이지 중 하나 이상이 채워져 있는가
- [ ] 시술(treatments) 배열의 길이 ≥ 1
- [ ] 장비(equipment) 배열의 길이 ≥ 1
- [ ] 위 5가지 중 4개 이상 충족 → 등록 진행 가능
- [ ] 시술과 장비 둘 다 0개 → 등록 보류 또는 robots noindex

## 4. 이메일 회신 준비 체크

병원에 첫 회신을 보내기 전 확인:

- [ ] 병원 홈페이지 URL을 이메일에 명시했는가
- [ ] 크롤링으로 확보된 시술 목록을 전체 나열했는가
- [ ] 보유 장비 목록을 전체 나열했는가 (한글명·영문명 병기)
- [ ] 크롤링으로 확인된 주소를 인용해 확인 요청 문구를 넣었는가
- [ ] 운영시간·다국어·가격 3가지 항목을 추가 확인 요청에 포함했는가
- [ ] 무료 운영 문구가 들어 있는가
- [ ] 서류 관련 안내(사업자등록증·의료진 정보 불필요)가 들어 있는가
- [ ] 서명이 "SCP 기획팀 / seoulclinicpick@gmail.com"으로 되어 있는가

## 5. DB 등록 전 최종 체크

병원 보강 자료를 받은 뒤 DB에 입력하기 전:

- [ ] 병원 기본정보 (name_ko / name_en / address / district / phone / website / hours)
- [ ] 다국어 상담 지원 필드 (foreign_languages 배열)
- [ ] 시술 목록 (categories 매핑 완료)
- [ ] 장비 목록 (device_name_ko / device_name_en / manufacturer)
- [ ] 시술-장비 매핑 (clinic_treatments의 devices_used 필드)
- [ ] 가격 정보 (공개하기로 한 경우만)
- [ ] 4개 언어 번역 확인 (한/영/일/중)
- [ ] 병원 페이지 URL 정상 접속 확인

## 6. 처리 완료 체크

- [ ] 병원 페이지가 4개 언어 모두 정상 표시되는가
- [ ] 시술 페이지에서 이 병원이 검색되는가
- [ ] 장비 페이지에서 이 병원이 매칭되는가
- [ ] 병원에 등록 완료 안내 이메일을 발송했는가
- [ ] s8-04 입점 이력 로그에 이 케이스를 기록했는가
